# Leonida Legend — GTA VI Trophy Guide & Tracker

An offline web app: guide and tracker for all 55 PlayStation 5 trophies of Grand
Theft Auto VI — checklist with localStorage progress, export/import, filters by
kind, a spoiler setting, a roadmap to the platinum, and every missable trophy
flagged. Each trophy's guide is written in our own words and cites its sources
(PlayStation's official list, PowerPyx, PSNProfiles, Exophase).

Static files under `app/` — serve them with any static HTTP server.
